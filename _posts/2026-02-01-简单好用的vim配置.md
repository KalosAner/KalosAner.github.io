### 前言

在一些没有网络的机器上安装编辑器很麻烦，但是很多Linux操作系统都自带vim编辑器，因此在很多场景下都需要使用vim。但是在使用vim的时候使用默认的配置会有很多不方便的地方，因此我会设置一下我喜欢的配置，如下是我常用的配置。

### 配置

配置时需要先在用户目录下创建一个`.vimrc`文件，可以使用如下命令直接编辑：


```
vim ~/.vimrc
```

配置如下，粘贴到`vimrc`里边就行：

```lua
" 1、显示行号
set number

" 2、jk 映射为 Esc
inoremap jk <Esc>

" 3、Tab 宽2，转为空格
set tabstop=2
set shiftwidth=2
set expandtab

" 4、右下角显示光标位置
set ruler

" 5、换行继承缩进
set autoindent

" 6、光标底部/顶部自动空出5行
set scrolloff=5

" 7、与系统剪贴板共享剪切、复制和粘贴
set clipboard=unnamedplus

" 8、将 Leader 键映射成空格键
nnoremap <Space> <Nop>
xnoremap <Space> <Nop>
let mapleader=" "

" 按 <Leader>w 快速保存
nmap <Leader>w :w!<CR>

" 取消高亮搜索
nmap <Leader>h :nohlsearch<CR>

" 9、使用 空格 + v 或 s 快速分屏
nnoremap <Leader>v :vsplit<CR>
nnoremap <Leader>s :split<CR>

" 10、优化多窗口切换（使用 Ctrl + 方向键）
nmap <C-h> <C-w>h
nmap <C-j> <C-w>j
nmap <C-k> <C-w>k
nmap <C-l> <C-w>l

" 11、底部栏显示文件名
set laststatus=2
set statusline=%t

" 12、设置paste快捷键
set pastetoggle=<F2>
```

### MacOS配置

习惯了使用vim之后在自己的笔记本上也会偶尔使用一下vim，但是MacOS上vim的配置不带高亮（Linux 默认带简单高亮），看起来很不方便。不过可以使用如下配置开启简单高亮，下面的配置同样放在`.vimrc`。

```lua
" ==========================================
" 适用于 macOS 的 ~/.vimrc 基础配置
" ==========================================

" 编码与兼容性设置
if v:lang =~ "utf8$" || v:lang =~ "UTF-8$"
    set fileencodings=ucs-bom,utf-8,latin1
endif
set encoding=utf-8
set nocompatible         " 使用 Vim 原生模式，关闭 vi 兼容

" 编辑体验优化
set bs=indent,eol,start  " 允许退格键删除任意字符
set history=50           " 历史命令记录 50 条
set ruler                " 右下角显示光标位置
set number               " 显示行号（建议开启）

" 记住上次打开文件时的光标位置
if has("autocmd")
  augroup resCur
    autocmd!
    autocmd BufReadPost *
      \ if line("'\"") > 0 && line ("'\"") <= line("$") |
      \   exe "normal! g'\"" |
      \ endif
  augroup END
endif

" 开启语法高亮与搜索高亮
syntax on
set hlsearch
set incsearch            " 输入搜索词时即时高亮匹配（建议开启）

" 开启文件类型检测、插件与自动缩进
filetype plugin indent on

" 适配现代 macOS 终端的 256 色支持
set t_Co=256

```
