# 2026-11-09

## 博客代码块行号重叠问题分析

用户反馈博客代码块左侧行号出现垂直重叠。已排查：

- 代码块由 Rouge 生成带 gutter 的 table，JS (`js/hux-blog.js`) 在 `$(document).ready` 中把 gutter 移除，并用 CSS counter 在 `.code-line::before` 中重新绘制行号。
- 相关样式在 `less/highlight.less`（编译到 `css/hux-blog.min.css`）。
- 本地用 Jekyll 构建并用 Chrome headless 截图复现，当前代码渲染正常，未出现重叠。
- 可能原因：`.code-line::before` 只设了 `position:absolute; left:0`，没有显式 `top`，垂直位置依赖静态位置；若浏览器字体、缩放、用户样式或缓存的旧 CSS 导致行高/定位计算偏差，就可能重叠。也可能是 Service Worker 缓存了旧版 CSS/JS。
- 建议修复：为 `.code-line` 和 `.code-line::before` 显式声明 `line-height`，并为 `::before` 加 `top:0`；必要时提升 SW 的 `CACHE_VERSION`。

后续待用户确认是否需要直接修改样式并重新构建 min.css。

## 2026-11-11 补充：找到并修复根本原因

用户反馈线上仍出现行号重叠，且刷新慢。经排查：

- 线上 HTML 仍是 Rouge 原始 table 结构（`<td class="rouge-gutter"><pre class="lineno">...</pre></td>`），说明 JS 的 `.code-line` 转换未执行。
- 根本原因是浏览器/Service Worker 缓存了旧版 `hux-blog.min.js`，导致新代码块的转换逻辑没有生效。
- 当前 CSS 没有给 `.lineno` 设置行高，因此 Rouge 原始行号在回退时挤成一团。

已做以下修复：

- `less/highlight.less` / `css/hux-blog.css` / `css/hux-blog.min.css`：为 `.lineno` 添加兜底样式（`display: block; line-height: 1.5; color: #636d83; user-select: none;`），即使 JS 未执行也不重叠。
- `_includes/head.html`：`hux-blog.min.css` 引用改为 `/css/hux-blog.min.css?v=2`，强制浏览器/SW 重新加载。
- `_includes/footer.html`：`hux-blog.min.js` 引用改为 `/js/hux-blog.min.js?v=2`，确保最新转换逻辑生效。
- `sw.js`：`CACHE_VERSION` 从 `'v4'` 改为 `'v5'`，`PRECACHE_LIST` 中对应 CSS/JS 改为带 `?v=2` 的 URL。

已重新构建并验证生成的 HTML 中引用的是带版本号的资源，CSS 中也包含 `.lineno` 兜底样式。

## 2026-11-11 二次补充：改用 flexbox 实现行号

用户反馈刷新时一瞬间正常（Rouge `.lineno` 正常），随后 JS 转换后的 `.code-line::before` 行号又重叠。这说明 `position: absolute` 方案在其实际环境下不可靠（可能被扩展、用户样式或浏览器对绝对定位静态位置的计算影响）。

已将 `.code-line` 从 `display: block; position: relative` + `.code-line::before` `position: absolute` 改为 **flexbox 行内行号**：

- `.code-line`：`display: flex; align-items: baseline; flex-wrap: nowrap;`
- `.code-line::before`：作为第一个 flex item，`flex: 0 0 2.6em; margin-left: -3.4em;`，不再使用 `position: absolute`
- `.code-wrap .code-line`：增加 `flex-wrap: wrap;`

修改文件：

- `less/highlight.less`
- `css/hux-blog.css`
- `css/hux-blog.min.css`
- `sw.js`：`CACHE_VERSION` 从 `'v5'` 改为 `'v6'`，强制 SW 重新预缓存新 CSS。

已重新构建并验证 `_site/css/hux-blog.min.css` 中 `.code-line` 为 `display:flex`，`.code-line::before` 无 `position:absolute`。
