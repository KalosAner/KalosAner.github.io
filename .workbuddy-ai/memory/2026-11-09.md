# 2026-11-09

## 博客代码块行号重叠问题分析

用户反馈博客代码块左侧行号出现垂直重叠。已排查：

- 代码块由 Rouge 生成带 gutter 的 table，JS (`js/hux-blog.js`) 在 `$(document).ready` 中把 gutter 移除，并用 CSS counter 在 `.code-line::before` 中重新绘制行号。
- 相关样式在 `less/highlight.less`（编译到 `css/hux-blog.min.css`）。
- 本地用 Jekyll 构建并用 Chrome headless 截图复现，当前代码渲染正常，未出现重叠。
- 可能原因：`.code-line::before` 只设了 `position:absolute; left:0`，没有显式 `top`，垂直位置依赖静态位置；若浏览器字体、缩放、用户样式或缓存的旧 CSS 导致行高/定位计算偏差，就可能重叠。也可能是 Service Worker 缓存了旧版 CSS/JS。
- 建议修复：为 `.code-line` 和 `.code-line::before` 显式声明 `line-height`，并为 `::before` 加 `top:0`；必要时提升 SW 的 `CACHE_VERSION`。

后续待用户确认是否需要直接修改样式并重新构建 min.css。

## 2026-11-10 补充：已修复

用户确认后，已修改以下文件：

- `less/highlight.less`：为 `.code-line` 添加 `line-height: 1.5`；为 `.code-line::before` 添加 `top: 0` 和 `line-height: 1.5`。
- `css/hux-blog.css`：同步上述更改（非压缩版）。
- `css/hux-blog.min.css`：同步上述更改（压缩版）。
- `sw.js`：`CACHE_VERSION` 从 `'v3'` 改为 `'v4'`，强制 Service Worker 重新预缓存。

已用 `bundle exec jekyll build` 重新构建站点，验证 `_site/css/hux-blog.min.css` 中已包含 `top:0` 和 `line-height:1.5`。
